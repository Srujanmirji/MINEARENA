Autonomous Extraction, Audited Where It Counts

Auditing 10-K SEC filings sits between two brittle extremes: manual spreadsheets are slow, while blind AI auto-approval causes silent financial misstatements. AuditLoop auto-approves routine, multi-verified metrics and suspends via LangGraph interrupt() only when confidence or accounting invariants fail.

0:00 Demo Intro
Failure Mode 1 · Manual Only

Slow & Unscalable

Analysts spend hours combing through 100+ page EDGAR HTML filings for 13 core income statement, balance sheet, and cash flow metrics plus footnotes and segments.

Failure Mode 2 · Pure AI Auto

Confidently Wrong

LLMs confuse restated priors, diluted vs. basic EPS, or scale units ($M vs $K). Without accounting checks and calibrated escalation, wrong numbers ship silently.

AuditLoop Solution

Calibrated Human-in-the-Loop

Cross-checks a deterministic HTML parser against an LLM extractor, enforces accounting invariants, and pauses execution cleanly in SQLite so reviewers inspect source table vs. SEC filing side-by-side.

11-Node LangGraph State Machine & Zero-Leak Isolation

Extraction nodes never see XBRL ground truth. Only verify_vs_xbrl is permitted to call get_xbrl_fact after human review finishes, eliminating benchmark leakage.

0:30 Architecture Slide

Anti-Cheat HTML Stripping

Inline XBRL ix: tags are stripped inside edgar/ before any extractor sees the filing—extraction operates purely on raw rendered HTML tables.

Zero-Write Pause Guarantee

When a filing escalates, human_review suspends inside LangGraph interrupt(). Final values and audit events commit only after apply_decision.

Tamper-Evident Audit Chain

Every row in audit_log stores prev_hash → hash (SHA-256) and triggers RAISE(ABORT) on any UPDATE or DELETE attempt.

Slide 3 of 4 · Scoring, Routing & Accounting Invariants

How Confidence Is Computed — And Overridden by Safety Rules

A high score alone never bypasses an accounting bug: failed invariants or weak label matches immediately override confidence and force human review.

Calibration & Safety
Deterministic Confidence Formula
C = 0.45 · Agreement + 0.30 · Label + 0.25 · Period/Unit
  • Agreement (45%): Parser A vs. LLM B numeric match (≤ 1% tolerance).
  • Label Match (30%): Line-item synonym score against target metric definition.
  • Period & Unit (25%): Exact FY end date + scale multiplier ($M/$B).
  • Derived Cap: Calculated metrics (e.g., FCF, inferred Liabilities) are capped at ≤ 0.75 so they always escalate.
Hard Auto-Approve Gate + Validation Checks

A value auto-approves only if all 4 hold: present AND C ≥ threshold (0.85) AND label ≥ 0.80 AND 0 failed checks.

A = L + E (0.5% tol) IS Hierarchy (GP ≤ Rev) Segment Sum ≈ Revenue YoY Swing (> 40% soft flag) Sign & Scale Plausibility

Even if C = 0.99, any failed check sends the item into the HIL review queue with one-click evidence highlight in the source SEC table.

Key Judge Takeaways (PS-01)

Why AuditLoop Ships Safely in Production

  • Safety-first routing: Accounting invariants & label floors veto high confidence—0 silent misstatements in 14 filings.
  • Zero ground-truth leakage: XBRL tags stripped before extraction; get_xbrl_fact gated to post-review verify/.

  • Adaptive human feedback (B-1): Reviewer decisions tune auto-approve threshold dynamically without weakening hard checks.
